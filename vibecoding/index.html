Python Camp: мини-курс в одном файле

Интерактивные задачи с автопроверкой. Код выполняется в браузере.

1. Основы: переменные и вывод

Теория: В Python переменные создаются присваиванием. print() выводит текст. Типы: int, float, str, bool.

Пример:

name = "Алекс"
age = 25
print(f"Привет, {name}, тебе {age} лет.")

Задача 1: Приветствие

Напиши код, который:

  • Создаёт переменную city со значением "Москва"
  • Выводит фразу: Я живу в [city]
Подсказка: используй f-строку f"Я живу в {city}".

2. Условия и логика

Теория: if / elif / else управляют ветвлением. Операторы сравнения: >, <, ==, !=. Логика: and, or, not.

Задача 2: Проверка возраста

Напиши код:

  • Переменная age = 17
  • Если age >= 18: вывести "Доступ разрешён"
  • Иначе: вывести "Доступ запрещён"
Проверь отступы: в Python они важны!

3. Циклы и списки

Теория: for перебирает элементы. range() создаёт последовательность. Списки: [1, 2, 3].

Задача 3: Сумма чисел

Напиши код:

  • Список numbers = [3, 5, 7, 9]
  • Посчитай сумму элементов и выведи результат
Можно использовать встроенную функцию sum() или цикл for.

4. Функции

Теория: Функции объявляются через def. Возвращают значение через return. Пример:

def greet(name):
    return f"Привет, {name}!"

Задача 4: Функция площади

Напиши функцию area_rectangle(width, height), которая:

  • Принимает два аргумента
  • Возвращает их произведение
  • Вызови функцию с width=5, height=10 и выведи результат
Функция должна возвращать значение, а не печатать его внутри себя.
