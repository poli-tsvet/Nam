Py Camp бесплатный интерактивный курс Python

Изучайте Python бесплатно.
Практика с первой минуты.

Платформа в духе freeCodeCamp: короткие уроки, живой редактор кода прямо в браузере, автоматические тесты и сертификаты за прохождение курсов. Встроенный интерпретатор Python — всё работает даже без интернета.

✔ Без регистрации ✔ Код выполняется прямо в браузере ✔ Автоматические тесты ✔ Сертификаты ✔ Один файл, полный офлайн

Учебные программы

Три сертификата: от первого print() до алгоритмов, ООП и анализа данных. Проходите уроки по порядку — каждый заканчивается автоматической проверкой кода.

🏆 Мои сертификаты

Выдаются автоматически после прохождения всех уроков и проектов программы.

Как устроено обучение

📖

Теория + практика

Каждый урок — короткий конспект с примерами и задание, которое нужно решить в редакторе кода.

⌨️

Живой редактор

Подсветка синтаксиса, автоотступы, консоль вывода. Запуск — кнопкой ▶ или Ctrl+Enter.

🧪

Автотесты

Кнопка «Проверить» прогоняет код через тесты, как в freeCodeCamp, и показывает, что именно не так.

🐍

Настоящий Python в браузере

Встроенный интерпретатор выполняет ваш код локально: переменные, циклы, функции, классы, файлы, regex и не только.

💾

Прогресс сохраняется

Пройденные уроки и ваш код сохраняются в браузере — можно закрыть страницу и вернуться позже.

🎓
